# 最佳化模型 Model Optimizer — Claude Skill

AI 自己開子代理（幫忙檢查、找檔案、讀資料的小幫手）時，不一定要用最貴的模型。這個 Claude Skill 讓 AI 依工作選合適的 Claude 模型：想得深的用 Opus，一般工作用 Sonnet，簡單查找用 Haiku。

## 怎麼選
- 規劃、設計、最後判定、獨立檢查：Opus
- 一般寫作、照步驟做、檢查計畫：Sonnet
- 找檔案、讀資料、列清單：Haiku
- Sonnet 或 Haiku 做失敗或被退回時，換高一級的模型重做一次。

## 限制
- 只管 AI 自己開的子代理；只用 Claude 的模型。
- 只在 Claude Code 桌面版用過；不保證能省多少 token。
- Skill 內容是繁體中文。
